# Mudra — Lightweight Paper+Live Trading App

A mobile-friendly web application for personal paper and live trading on **crypto (Binance)** and **Indian equity markets (Zerodha)**.

## Features

✅ **Manual trading** — enter trades with SL/TP  
✅ **Auto SL/TP** — positions auto-close when triggered  
✅ **Basic strategies** — MA 20/50 crossover signals  
✅ **Paper + Live mode** — toggle between simulated and real trading  
✅ **Trade history** — persisted trades with PnL tracking
